# 0005 자막은 웹 페이지 클립으로 만들고 .vtt 는 가져오기 소스로만 쓴다

Status: accepted
Origin: 커밋 abb112e 의 u3/CONCEPT.md 「추가하는 세 가지 · 자막」 결정(사람이 작성)
Source: packages/openfilm/studio/server/film-subtitle.mjs

## 맥락
openfilm 자막은 film 이 아니라 Studio 가 그린다. 원본은 `.vtt` 이고 스타일은 film 당 하나다. u3 자막은 클립 단위 이동·트림, 레이어 여러 개, 메인·서브 두 줄, 클립별 스타일·강조(`*단어*`)·등장 효과가 필요하다. 그래서 이 기능은 추가가 아니라 대체다.

## 결정
- 자막 한 줄은 웹 페이지 클립 하나다.
- `.vtt` 는 자막 클립을 만드는 가져오기 소스로만 쓴다.
- 자막 프롬프트(대본, 말투, 성격, 전역 자막 지침)는 skill 에 둔다. 코딩 에이전트가 LLM 역할을 한다.
- 받아쓰기는 whisper.cpp 를 `asr` provider 로 넣어 기존 「자막 만들기」 버튼에 연결한다.

## 결과
- 자막이 타임라인의 다른 클립과 같은 방식으로 편집된다.
- 기존 Studio 자막 기능(번역, SRT 내보내기)은 자막 클립에는 동작하지 않는다. 처리 방식은 자막 클립 변경의 intent 에서 정한다.
- 등장 효과를 `frame(t)` 로 그리는 것은 추정이다. 자막 클립 변경의 spec 에서 실측한다.
