# u3 자막 클립

u3 자막에서는 이 skill이 공식 `long-to-short`의 “Studio draws the subtitles” 지침보다 우선한다. 자막은 페이지 클립이 그린다. `u3sub-` 클립이 있는 film에서는 Studio 자막 cue가 나오지 않는다. 기존 `.vtt`와 `subtitles.json`은 그대로 둔다.

## 대본과 화자

사용자가 준 상황과 화자 설정을 먼저 따른다. 설정이 없으면 친구에게 보내는 짧은 한국어 속말을 쓴다. 한 장면에는 새 생각·반응·선택 하나를 담는다. 보이는 상품과 동선을 나열하거나 같은 반응을 다른 컷에서 반복하지 않는다. 새로 말할 내용이 없으면 자막을 생략한다.

말투는 빠르고 편한 반말이다. 재미있는 장면에는 셀프드립과 능청스러운 반응을 쓰고, 조용한 장면에는 담백하게 쓴다. 성격은 친구 단톡에 현장 반응을 보내는 구경꾼이다. 초성·ㅋㅋ·이모지·밈은 장면과 말맛에 맞을 때만 쓴다. 모든 컷에 농담이나 광고·CTA를 넣지 않는다.

화자의 작은 방문 목적은 창작 설정으로 정할 수 있다. 실제 구매·사용·시향·효능·타인 후기는 만들지 않는다. 상품명·성분·가격·표지판은 해당 장면에서 확인한 것만 쓴다. 영어 서브 자막은 같은 화자·대상·행동·시점·확실성을 유지한 자연스러운 영어로 쓴다. 번역에 새 사실을 넣지 않는다.

## 전역 자막 지침

- 표시 시간 안에 읽을 수 있는 길이로 쓴다. 한 화면에는 자연스러운 생각 하나를 둔다.
- 한국어 한 줄 16자, 초당 12자를 가독성 참고값으로 쓴다. 영문·공백·문장부호는 각각 0.5자로 센다. 의미와 자연스러운 말투를 먼저 지킨다.
- 가급적 한 줄로 쓰고, 길면 의미 단위로 최대 두 줄로 나눈다. 단어·조사·어미를 떼지 않는다.
- 문장 끝 마침표와 쉼표는 원칙적으로 생략한다. 물음표·느낌표는 감정에 맞게 쓴다. 말줄임표는 실제 끊김과 망설임에만 쓴다.
- 원본 시각과 길이를 지킨다. 전체 자막을 이어 읽고 반복과 화면에 맞지 않는 사실을 고친다.
- 이 지침은 새로 쓰는 SNS 대본용이다. 받아쓰기와 번역은 원래 발화의 의미와 싱크를 유지한다.

## 가져오기와 편집

다시 가져오면 같은 레이어의 기존 가져오기 클립을 교체한다. 그 클립에서 고친 글과 스타일 재정의도 사라진다. 다시 가져오기 전에 필요한 편집을 보관한다.

```sh
openfilm get subtitles --src assets/audio/voice.vtt --layer narration
```

`.vtt`는 프로젝트 안의 파일이다. `--layer` 기본값은 `layer1`이다. cue 하나가 클립 하나가 된다. 겹치는 cue는 앞 cue의 끝을 다음 cue의 시작으로 줄인다. 시작 시각이 같은 cue는 먼저 정리한다. 단어 timestamp와 화자 태그는 표시하지 않는다. 가져온 글의 별표는 글자로 보존한다.

Studio에서 클립을 고르고 `메인`, `서브`, `튀어나옴`, `떠오름`, `흔들림`, `색`, `크기`, `강조색`을 편집한다. 서브가 비면 서브 줄을 숨긴다. `*단어*`는 강조색이고 `\*`는 별표 글자다. 강조색 기본값은 `#FFB020`이다. 새 대본을 가져온 뒤 강조할 부분만 `메인`·`서브`에서 `*단어*`로 고친다.

효과는 세 변수를 모두 `0`으로 두면 none이다. pop은 `--u3-pop: 1`, rise는 `--u3-rise: 1`, shake는 `--u3-shake: 1`로 두고 나머지는 `0`으로 둔다. 효과는 페이지 시각 0–0.3초에 동작한다. 앞을 0.3초 이상 자른 클립과 split 오른쪽 조각에는 효과가 없다. `--u3-scale`은 0.5–2로 제한된다.

레이어 전체 스타일은 `scenes/u3-subtitle-<layer>.html`의 `:root`를 고친다. 폰트는 `--u3-font`의 `Pretendard`, `'Gmarket Sans'`, `TmonMonsori`다. 메인·서브 크기는 `--u3-main-size`·`--u3-sub-size`에 CSS 길이로 쓴다. 글 색은 `--u3-color`, 위치는 `--u3-x`·`--u3-y`다. 자막바는 `--u3-bar`의 0·1, 색은 `--u3-bar-color`, 불투명도는 `--u3-bar-opacity`의 0–1이다. 기존 레이어 페이지와 폰트는 재가져오기 때 덮어쓰지 않는다.

`openfilm look`으로 가독성과 효과를 확인한다. Studio 번역·SRT 내보내기·burn-in·NLE 자막 트랙은 자막 클립 film에 cue를 내지 않는다. 페이지 자막은 영상 자체에 그려진다.
