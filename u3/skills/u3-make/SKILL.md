# u3 장면표로 film 만들기

다시 실행하면 `data-u3-make` 속성이 있는 클립의 손 편집을 교체한다. 보존할 클립에서는 이 속성을 먼저 지운다. id를 바꾸는 것만으로는 보존되지 않는다. 다른 클립은 그대로 둔다. make 클립의 트랙이 locked이면 잠금을 해제한 뒤 실행한다. `get subtitles`에는 `make`로 시작하는 레이어 이름을 쓰지 않는다.

## 순서

1. 프로젝트의 원본 영상과 길이를 확인한다. 원본을 `look`으로 본다.
2. `openfilm get asr --src assets/video/input-a.mp4`로 받아쓰기를 준비한다. 이미 받아쓴 파일은 다시 만들지 않는다. 영상 옆의 같은 이름 `.vtt`를 읽는다. 예: `assets/video/input-a.mp4` → `assets/video/input-a.vtt`. cue 시각과 단어 timestamp는 **원본 영상 기준**이다. 장면을 잘라도 `.vtt` 시각을 다시 쓰지 않는다.
3. 받아쓰기와 화면에서 확인한 내용으로 프로젝트 안에 `scenes.json`을 쓴다.
4. `openfilm get make --scenes scenes.json`을 실행한다.
5. receipt의 순위 방식·이유, 누락 수, 고른 짤·효과음을 확인한다. `openfilm look` 연락표로 자막 가독성과 짤 배치를 확인한다. `openfilm render`로 끝까지 내보낸다.

## 장면표

```json
{
  "title": "오늘의 반응",
  "inputs": ["assets/video/input-a.mp4", "assets/video/input-b.mp4"],
  "scenes": [
    {
      "inputIndex": 1,
      "startSec": 0.3,
      "endSec": 3.0,
      "caption": "이건 *예상 밖*인데",
      "subCaption": "That was *unexpected*",
      "reaction": "놀람",
      "memeBefore": false,
      "memeAfter": true,
      "sfxCategory": null
    },
    {
      "inputIndex": 2,
      "startSec": 1.0,
      "endSec": 4.0,
      "caption": "잠깐만 다시 보자",
      "subCaption": "Wait, let me look again",
      "reaction": null,
      "memeBefore": false,
      "memeAfter": false,
      "sfxCategory": null
    }
  ]
}
```

`inputs`는 프로젝트 안 영상 파일 1–20개다. 사진 장면은 받지 않는다. `inputIndex`는 **입력 항목 번호(1부터)**다. 첨부 프레임의 번호나 프레임 시각을 입력 번호로 쓰지 않는다. 각 영상의 프레임은 해당 입력 항목의 원본 초 단위 시각으로 읽는다. `0 ≤ startSec < endSec ≤ 원본 길이`를 지킨다. `title`은 선택이며 30자 이내다. title은 장면표 설명이고 타이틀 클립은 만들지 않는다. `caption`은 비어 있지 않은 문자열이고 `subCaption`은 선택이다. 별표는 그대로 강조로 전달한다.

`reaction`은 인정, 분노, 귀찮음, 기대, 소름, 당황, 의심, 부끄러움, 억울, 웃음, 뿌듯함, 체념, 놀람, 감동 또는 `null`이다. reaction이 있으면 앞·뒤 중 한 곳만 true로 쓰는 것을 기본으로 한다. 반응을 먼저 보여주면 `memeBefore`, 상황 뒤에 보여주면 `memeAfter`를 쓴다. 둘 다 false이면 뒤에 놓는다. 둘 다 true이면 1위·2위를 앞·뒤에 놓는다. 두 번째 후보가 없으면 뒤 하나만 놓는다. reaction이 null이면 앞·뒤 모두 false로 쓴다. 각 원본에서 반응 장면을 하나 이상 찾되 맞는 반응이 없으면 null을 유지한다.

`sfxCategory`는 shock, fail, laugh, applause, alarm, impact, bruh, notify, pop, reveal 또는 `null`이다. 명시한 분류가 우선이다. null이면 고른 짤의 감정, 그다음 장면 reaction에서 분류를 얻는다.

## 대본 작성

사용자가 준 상황·말투·성격을 먼저 따른다. 기본은 친구에게 바로 보내는 짧고 자연스러운 한국어 SNS 속말이다. `u3-subtitles`의 화자·말투·가독성 지침을 함께 따른다. 장면마다 새 생각·반응·선택 하나를 담는다. 상품명·색·매대·동선을 나열하거나 앞 장면의 발견·망설임을 반복하지 않는다. 새로 말할 내용이 없는 구간은 장면표에서 뺀다. 영상 요약·상품 설명·활동 기록으로 쓰지 않는다.

작은 방문 목적은 창작 설정으로 정할 수 있다. 실제 구매·사용·시향·효능·타인 후기는 만들지 않는다. 상품명·가격·표지판은 해당 장면에서 확인한 것만 쓴다. 보이는 물리 동작은 두 언어에서 같은 동작으로 쓴다. 영어 subCaption은 화자·대상·행동·시점·확실성을 유지한 자연스러운 번역이다. 새 사실이나 한국어에 없는 제품 주장을 넣지 않는다. 읽기 어려운 어휘 결합과 반복을 전체 자막에서 확인한다.

짤·효과음은 장면에서 의미가 있을 때만 요청한다. 대본 초안에서는 장면당 짤 요청과 명시적 효과음 요청 중 하나만 고르고, 두 요청 중 하나라도 있는 장면을 전체에서 최대 두 장면으로 제한한다(u3 기본 프롬프트). 생성기는 아래의 원본당 짤 보충과 감정 기반 효과음을 별도로 적용한다.

## 배치 규칙과 결과

장면을 빈틈 없이 붙인다. 같은 원본의 맞닿은 컷(경계 차이 0.05초 이내)은 영상 클립 하나로 합친다. 자막은 장면별 메인·서브 클립이다. film의 무대 크기를 유지하고 원본 영상을 cover로 채운다. 가로 원본을 세로 무대에 놓으면 양옆이 잘린다.

짤 질의에는 caption과 reaction만 쓴다. 서브 자막은 검색에 넣지 않는다. 앞 짤은 장면 시작, 뒤 짤은 장면 끝에 맞춘다. 길이는 짤 길이·2초·장면 길이 중 최솟값이다. 짤은 가운데, 무대 폭 60%, 소리 끔으로 놓는다. 높이가 무대를 넘으면 높이에 맞춰 줄인다. 같은 짤을 두 번 쓰지 않는다. 사람이 남긴 짤도 제외한다. 짤 없는 원본은 후보가 있는 마지막 장면의 끝에 그 장면의 1위를 보충한다. 크기·길이가 없는 짤은 쓰지 않는다. 후보가 없으면 누락 수를 receipt에 적는다. 라이브러리 자체가 없으면 `node u3/scripts/fetch-library.mjs`로 받는다.

효과음은 그 장면의 첫 짤이 나타나는 시각에 최대 1.5초로 놓는다. 짤이 없는 장면에서는 장면 시작에 놓는다. 파일 길이가 더 짧으면 그 길이를 쓴다. 같은 장면표 해시와 장면 번호에서 같은 파일을 고른다. 도입 알림과 전환 효과는 넣지 않는다. 트랙은 위에서 아래로 자막, 짤, 원본 영상, 효과음 순서다. 짤과 효과음이 겹치면 가장 아래 빈 트랙을 쓴다. 원본 소리는 유지한다.

순위 방식은 실행 시작에 고정한다. 임베딩 모듈·검증된 모델·색인·docHash가 모두 맞으면 embedding, 그 외에는 rule이다. 실행 중 임베딩이 실패하면 전체를 rule로 다시 계산한다. receipt는 장면 수, 길이, 고른 짤·효과음 id, 순위 방식과 이유를 낸다. 같은 장면표·라이브러리·순위 방식과 남겨 둔 사람 클립에서는 같은 film.html을 만든다.
